Quiet Shelf 0.16.0 adds Read next across Android, Windows and the browser version.

- Generate an on-device checklist of up to 12 suitable unread titles, with balanced, quick-read and series modes plus an optional genre filter. Weighted randomness varies new mixes; when alternatives exist, replacement changes membership. Generation never runs automatically or requires an AI service.
- Suggest at most the next unread volume in each series. Unfinished or missing earlier volumes prevent jumping ahead. Series progress, unread volumes owned, format/page estimates and time since registration influence priority. Finishing a volume checks it off without advancing the list.
- The saved checklist shows unread, in-progress and completed entries with a counter and progress bar. Replacing an unfinished list requires confirmation. Keep only the current checklist, available offline in its guest/account workspace, backups and optional Drive sync.
- A separate manual action refreshes missing ISBN information from Open Library and Google Books in bounded batches. Cache exact matches, keep API keys device-local, respect offline/metered connections and keep suggestions usable when catalogs lack data. Title details offer reversible exclusions and format estimates; study/reference titles are skipped by default.
- Add Blackwell’s (UK) and Better World Books (US) as separate in-app edition search/import sources, without connectors, store accounts or extra API keys. Verify ISBNs and explicit language filters against edition details.
- All catalog sources now default to Any language. Manually selected language filters remain remembered.

Install Android updates over the existing app using the same signing identity. Windows updates remain under Account → App updates. Preserve the local browser private runtime folder when updating its files. Update all clients before syncing the new checklist/metadata fields; older clients reject unfamiliar data without replacing the shelf.

Checks cover selection/sequencing, varied membership, effort estimates, exclusions, frozen progress, replacement cancellation, offline storage, explicit ISBN lookup/cache, backup validation and guest/account isolation. Release checks also exercise the real Windows/browser interface and Android emulator, including checklist persistence after restart. Real-device Google consent and document pickers still require interactive verification.
